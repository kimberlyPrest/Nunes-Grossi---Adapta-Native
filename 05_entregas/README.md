## Código do sistema

`central-do-fluxo-comercial/` é um **submódulo** que aponta para o repositório de código gerado pelo Skip:
https://github.com/louisecorretorang/central-do-fluxo-comercial-n-g-y56w80iqy

- Para baixar junto com este repositório: `git clone --recurse-submodules <url-deste-repo>`
  (ou, se já clonou, `git submodule update --init`).
- Para trazer a versão mais recente do código: `git submodule update --remote 05_entregas/central-do-fluxo-comercial`
  e faça commit da nova referência.
- Não edite o código por aqui: mudanças no sistema saem como task executada pelo Maestro no Skip.
